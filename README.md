# Morning Vibe Check

Quiz scurt (5 intrebari) despre rutina de dimineata. La final primesti unul din cele 3 profiluri (Dirijorul, Pragmaticul, The Diva), bateria de energie, mixul raspunsurilor si o mica provocare pe care o poti da mai departe.

## Cum il rulezi

Pagina e un singur fisier HTML, fara build si fara dependente (fonturile vin din Google Fonts).

- Local: deschide `index.html` in browser.
- Online: activeaza GitHub Pages din Settings > Pages, sursa `main` / root.
